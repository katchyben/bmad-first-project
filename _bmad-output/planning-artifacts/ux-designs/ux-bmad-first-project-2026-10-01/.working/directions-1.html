Design directions: Today view

Four ways to build the same screen in Graphite Hush. Colour, content and overdue rules stay the same in all four. What changes is density, type, how row actions show up, where you add a task, and how things move. Scroll sideways to compare. Each column has the main mock, one state variant and a small dark-mode thumbnail.

Direction A

Still Water

Lots of white space, light type, and nothing on screen you don't need yet. The add field sits at the top, ready to type into, and row actions show up only when you hover or focus a row. It is the quietest of the four. Good if the list is usually short.

Density
Airy. 58px rows, one narrow column (560px)
Type
32/300 heading, 16/400 rows
Add task
Inline input at top. Enter adds it
Actions
Show on hover / focus, replacing the due date
Motion
Opacity fades only, 180ms. Nothing slides

Direction B

Ledger

A tight, table-like list that fits a lot on one screen. Every action is always visible as a small button, so nothing is hidden. A “New task” button opens a short dialog. This one is plain and quick to use, and it scales best as the list grows.

Density
Compact. 40px rows, full-width table with columns
Type
18/600 heading, 13/400 rows, tabular dates
Add task
“New task” button (N) opens a dialog
Actions
Always visible, xs outline buttons
Motion
Close to instant (100ms). Dialog fades, no movement

Direction C

Desk Lamp

A bold heading over a list of separate rows, with a side panel that is always open for adding and editing. Row actions sit behind a “⋯” menu, so the list stays tidy and you're never more than one click from them. It feels the most like a work tool. Good if you edit tasks often.

Density
Medium. 48px card rows, list plus a 210px panel
Type
26/700 tight heading, 15/500 rows
Add task
Side panel, always open. It also hosts Edit
Actions
Overflow “⋯” menu per row (Radix dropdown)
Motion
Menu scales in from 96%, 120ms. Panel cross-fades between Add and Edit

Direction D

Index Card

Soft rounded cards and a composer fixed to the bottom of the window, like a message box. Actions show up only on the card you select, with a key shown for each, so you can work through the list with the keyboard. It is friendly, and the motion is a little more noticeable than in the others.

Density
Medium-airy. Separate 14px-radius cards with 8px gaps
Type
22/500 heading, 15/400 rows, pill controls
Add task
Composer bar fixed to the bottom (⌘K focuses it)
Actions
Selected card expands into an action bar with keys
Motion
Card grows to height, 180ms ease-out. Finished rows slide into “Finished”
